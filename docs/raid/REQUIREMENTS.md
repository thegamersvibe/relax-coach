# Relax Raid requirements

Target: `forever` only (Interface 16001). IDs are stable and are the ones the design uses.
"Need" is the raid by which the requirement must work: 1 is the silent first raid, 2 the second, 3 the third.
State is `open` for every row until its validation row in `IMPLEMENTATION-MATRIX.md` passes.

## Completion criteria

A phase is complete when every row with that Need is `verified` in the matrix, the full `tools/raidtest.py --all` run and the existing CI are green, and the remaining in-game checks are listed as not run.
