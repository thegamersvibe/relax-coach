## Implemented boundary

`Score([]model.Fight, []model.Death, []model.PrepReport, cfg.Config)` returns
`[]model.NightScore` with nested fight/part scores and no sidecar. Production
imports are stdlib, model and cfg only. Per-fight views come from retained
Events; role, health attribution, ownership, server duration and real deaths
are not inferred from parser internals. Index-only/unknown/missing-role inputs
remain unscored. Partial fights remain visible but unscored.

Output uses role medians for DPS and tanks, healer team/individual halves,
effective healing and consumed absorbs, with no lone relative baseline.
Activity uses completed cast intervals plus post-cast GCD (energy-aware),
melee intervals, interval union and alive clipping; RANGE/failed casts/pet
uptime do not create activity. Mechanics uses explicit player ownership,
early/late death severity and non-tank landed boss swings. Utility is evidence
only. Preparation uses shared exact/ASCII matching, any-night readable stock,
END-inclusive/earliest report choice, distinct gear slots and NotScored skips.
Both prep clocks and every measure's availability/points are exposed.

Coverage, provisional scoring and competition ranks are separate. Fixtures
verify DPS 80/74, paired healers 70/64, lone healer 33/27, paired tanks 54/48 and
lone tank 24/18 (with/without preparation). A 54-coverage tank has a score but
no rank and consumes no rank position. Coverage 14 is unscored; 15 is scored.
`ValidatePart` and `Validate` in `score/validate.go` reject invalid measured
metadata, and `Score` invokes the guard before returning. A boundary test
forces invalid generated coverage to prove the call cannot silently disappear.

## RED / GREEN

five tests; they were retained only after review and behavioral mutation checks.

missing swing coverage and unchanged death points; healer tests failed on

only the first fight (100.0 instead of weighted 92.0). End/tail healer tests
exposed lost alive-at-death state. A fractional coverage threshold test exposed
inconsistent fight/night comparisons. Each production correction was followed
by a passing focused/package run.

operand removal), one survivor (cause filtering concealed the ownership guard).

survivor. The fractional-threshold regression adds one mutation.
