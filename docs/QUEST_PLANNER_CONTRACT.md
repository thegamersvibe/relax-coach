# Relax Quest Planner: build contract (2026-11-09)

Goal: tonight's public **test pre-release**. It has two features: **Dungeon quests**, which picks a dungeon and builds a route with every quest and its prerequisites, and **Pick my guide**, a Zygor-style scan of the Journey guides that picks the best one and pins you to the first undone step. A third entry point, **Get this quest/reward**, builds a route to one quest. Both features run inside Relax Journey and must also work standalone. The work must cover every class, race (Skyborne included), faction and level. Nothing may be specific to one character.

## Hard rules
- **Ship no third-party data.** QuestieDB, Questie, FDJ (ForeverDungeonJournal) and DungeonGuideForever data is read at runtime from the user's own installed addons. Commit no generated tables derived from them. Optional deps: `QuestieDB, ForeverDungeonJournal, DungeonGuideForever, Journey`. Without QuestieDB, fall back to FDJ/Dungeon Questie only and say so in the UI.
- WoW Forever client: Interface 16001, **Lua 5.1**. Modern APIs: `C_QuestLog.*` (GetAllCompletedQuestIDs, IsQuestFlaggedCompleted, IsOnQuest, ReadyForTurnIn, IsComplete, GetNumQuestLogEntries, GetInfo, GetTrivialRange), `C_SkillInfo.GetNumSkillLines/GetSkillLineInfo` (record), `C_Reputation.GetNumFactions/GetFactionDataByIndex` (record), `C_Map.SetUserWaypoint`, `UiMapPoint.CreateFromCoordinates`, `C_SuperTrack.SetSuperTrackedUserWaypoint`. There is NO global GetSkillLineInfo/GetFactionInfo/GetQuestsCompleted/GetQuestLogTitle. Unit numbers can be **secret values**: guard with `issecretvalue`. Never do math on player health. Wrap every event handler in pcall and store errors in `RelaxQuestPlannerDB.lastError`. `%d` rejects floats, so floor first. `tonumber((select(n, ...)))` needs the extra parentheses.
- No frame freezes. Planning over about 5k quests must be time-sliced with coroutines (≤ about 8 ms per frame), with a callback when done.
- Race/class masks come from `LibQuestieDB.Enum.raceMaskById[raceID]` (race ID = 3rd return of `UnitRace`) and `LibQuestieDB.Enum.classKeys`. Masks can exceed 32 bits, so never use `bit.band` on them; use arithmetic (`math.floor(mask / m) % 2`).
- Do not git commit or push. The parent integrates. Only touch files your lane owns.

## Global namespace: `RelaxQuestPlanner` (alias RQP)
### Lane A: data + engine (`addon/RelaxQuestPlanner/Core/*.lua`)
- `RQP.Data.Ready() -> ok, reason`; `RQP.Data.Source()` -> "QuestieDB"|"FDJ-only"
- `RQP.Data.Quest(id) -> row|nil`. Row fields: id,name,reqLevel,qLevel,races,classes,grp,single,excl,zone,next,special,parent,bcFor,bcs,untilDone,startingWith,disabledBy,maxLevel,skill,ranks,spec,minRep,maxRep,spell,startedBy,finishedBy,objectives, plus `fdj={pickup,turnin,dungeon}` for FDJ supplements. Lists are never nil.
- `RQP.Data.AllQuestIds()`, `RQP.Data.Npc(id)`, `RQP.Data.Object(id)`, `RQP.Data.Item(id)`, `RQP.Data.Dungeons() -> { {name, areaIds={...}} }` (from QuestieDB support ZoneDB dungeons + FDJ.DB names; drop battlegrounds)
- `RQP.Data.Pin(kind, id) -> {map, x, y, who, zone}|nil` (npc/object spawns via areaId→uiMapId; FDJ `QUEST_START_MAPS` for FDJ-only quests; x/y in 0-100)
- `RQP.Player.Snapshot() -> {level, raceMask, classMask, faction, done=set, log=set, ready=set, professions={name=rank}, trivial}`
- `RQP.Engine.State(qid, P, opts) -> state, reasons`. States: available, blocked, unknownGate, done, inlog, race, class, blacklisted, repeatable, holiday, superseded, exclusive, breadcrumbObsolete, expired, overLevel (same semantics as the Python one)
- `RQP.Engine.Unlocks(qid, P) -> {qid...}` (simulated turn-in flip, whole chain, breadcrumbs excluded)
- `RQP.Engine.BuildPathAsync(dungeonName, P, opts, cb)` and `RQP.Engine.BuildGoalAsync(questID, P, opts, cb)`. opts.mode = "game"|"strict"|"all". `cb(route)`. Route = `{title, level, floor, steps={ {kind="accept"|"complete"|"turnin", q, name, who, zone, map, x, y, note, needs={qid}, below=bool, levelOK=bool, source="QuestieDB"|"FDJ"|"DungeonQuestie", confidence="db"|"addon"|"observed"} }, later={...}, issues={...}}`. Order: pick up outside (grouped by zone), then in the dungeon, then turn in (grouped by zone).
- `RQP.Learn.Record(kind, qid, npcID)`, `RQP.Learn.Observed(qid) -> set` of quests turned in right before qid was accepted from the same NPC/session. Accepting a quest whose DB prereqs aren't met refutes the claimed prereq: store it in `RelaxQuestPlannerDB.learn`.
### Lane B: UI (`addon/RelaxQuestPlanner/UI/*.lua`, `RelaxQuestPlanner.toc`, `Init.lua`)
- Step window (based on the private RelaxDungeonPath prototype at `/opt/data/projects/relax-coach/private/RelaxDungeonPath/RelaxDungeonPath.lua`): shows the first undone doable step, preferring the current zone. Map button = waypoint + supertrack.
- Dungeon picker (list of dungeons with quest counts for this character), level-mode setting (Strict -5 / Game default trivial range / Show all), below-floor items marked "your choice" with the reason (unlocks N / reward), "Get this quest" by ID or shift-click link.
- Slash `/rqp` (help, dungeon <name>, guide, goal <id>, mode <m>, map, hide). Shows "QuestieDB missing: limited data" when needed.
### Lane C: Journey integration (`addon/Journey/*` minimal patch + `addon/RelaxQuestPlanner/Journey/*.lua`)
- Minimal, clearly marked patch (`-- Relax local guides` comments) that exposes `_G.RelaxJourneyAPI`: `RegisterLocalGuide(guideID, info, buildFn)`, `Goto(guideID, stepID)`, `ListCatalogGuides()`, `ScanGuideQuests(guideID) -> {accept={},turnin={},complete={}}` (async, decoded via Journey's own loader). Local guides resolve before the signed catalog branch. Signed/hash/expiry behaviour stays byte-identical for catalog guides.
- `RQP.Journey.ToGuide(route)` converts a route into a Journey guide table (step syntax: see the existing generated examples in `/opt/data/projects/relax-coach/evidence/journey-picker-study-2026-11-09/dungeon-path/examples/*.journey.lua`).
- Pick my guide: scan every catalog guide matching the player's conditions (faction/race/class), score it (remaining doable quests, log overlap, level fit, future unlocks via `RQP.Engine.Unlocks` when present; hard filter on the level mode), present the top 3, then Goto the first undone step. The scan is async.
