Release notes

Check to see the latest release notes.

Install and Update use the same verified transaction. From 1.4.2 they install ForeverCoach, Journey and Journey-Content together, with verified backups. From 1.5.0 it also installs RelaxQuestPlanner (Relax Quest Planner); an existing RelaxQuestPlanner folder, such as a manually installed test version, is moved into the backup in RelaxCoachBackups, not deleted. The addons remain independent. Settings, saves, progress and unrelated addons are preserved. The bundled EXE and installers are never installed or run. Update App remains separate. Legacy packages below 1.4.2 update Coach only.

More addons

Optional addons made for WoW Forever. Each one installs into its own folder and updates separately from Coach.

Install and Update download only the stable GitHub release of that addon, verify its SHA256 checksum, check the archive and TOC, and keep a backup of the previous version in RelaxCoachBackups, like the Relax Coach addons above. WoW can stay open. Settings, saves and other addons are not touched.
